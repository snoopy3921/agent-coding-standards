# Agent Coding Standards

Reusable coding conventions and formatting rules for OpenAI Codex.

## Supported Languages

- **C/C++** — Available
- **Python** — Planned
- **Rust** — Planned

## Usage

Clone this repository, then ask Codex in the target project:

> Apply the coding standards from `~/workspace/agent-coding-standards` to this project. Set up the relevant conventions, formatter, and `AGENTS.md` instructions. Preserve existing project-specific rules and keep agent instructions minimal.

Codex should only apply standards relevant to the project's programming languages.
